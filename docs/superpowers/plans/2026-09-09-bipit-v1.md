# bipit v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship bipit v1 — a portable, single-skill agent pack that turns the current agent session into build-in-public content, installable across Claude Code, Codex, opencode, and Cursor.

**Architecture:** No runtime code and no daemon. The deliverable is a markdown skill (`skills/bipit/SKILL.md` + `references/*.md`) plus a POSIX-`sh` installer (patterned on `konten-studio/jekardah-writer`) that symlinks the one skill directory into each harness's discovery path. A Node `bin/cli.js` wraps the installer for `npx bipit`. The skill itself instructs the host agent to bootstrap and maintain a `~/bipit/` git workspace.

**Tech Stack:** Markdown, POSIX `sh`, Node ≥18 (CLI wrapper + tests via `node:test`), git. No third-party npm dependencies.

**Spec:** `docs/superpowers/specs/2026-09-09-bipit-v1-design.md`

## Global Constraints

- Repo: `konten-studio/bipit`. License: MIT. npm package name: `bipit`.
- `skills/bipit/` is the single source of truth — no forked skill copies anywhere in the repo.
- bipit ships **no** transcript-parser code; `references/session-sources.md` documents locations and formats for the host agent to read with its own tools.
- One skill only (`bipit`). The four modes (`brainstorm`, `draft`, `knowledge`, `publish`) are workflows inside it, not separate skills.
- `SKILL.md` / `references/*.md` agent-instruction prose in English; user-facing copy (mode prompts, README, AGENTS.md blurb) bilingual EN + ID.
- Installer: POSIX `sh`, `set -eu`, default `symlink` method, refuse-overwrite, reject `--prefix` containing `..` / `./` / control chars, `.bipit-install.tsv` manifest, `EXIT`-trap cleanup of partial installs.
- Installer agent→dir map — user scope: claude `~/.claude/skills`, codex `~/.codex/skills`, cursor `~/.cursor/skills`, opencode `~/.config/opencode/skills`; project scope: claude `.claude/skills`, codex `.agents/skills`, cursor `.cursor/skills`, opencode `.opencode/skills`.
- Node tests use the built-in `node:test` runner — no jest/mocha/bats.
- `publish` mode finalizes only: no per-platform formatting, no clipboard, no browser, no API.
- Fact-lock in `draft`: never invent metrics, outcomes, dialogue, or causality absent from the session.
- Commit frequently, one commit per task minimum.

```sh
# shellcheck shell=sh
# Sourced by install.sh / uninstall.sh / tests. No side effects on source.

bipit_validate_prefix() {
  _p=$1
  case "$_p" in
    /*) ;;
    *) echo "Prefix must be an absolute path" >&2; exit 2 ;;
  esac
  case "$_p" in
    *'/../'*|*/..|*'/./'*|*/.) echo "Unsafe prefix: path traversal segments are not allowed" >&2; exit 2 ;;
  esac
  if [ "$(printf '%s' "$_p" | wc -l | tr -d ' ')" -ne 0 ] || printf '%s' "$_p" | grep -q "$(printf '\t')"; then
    echo "Unsafe prefix: control characters are not allowed" >&2; exit 2
  fi
}

bipit_resolve_reldir() {
  _agent=$1; _scope=$2
  case "$_scope" in
    user)
      case "$_agent" in
        claude) echo ".claude/skills" ;;
        codex) echo ".codex/skills" ;;
        cursor) echo ".cursor/skills" ;;
        opencode) echo ".config/opencode/skills" ;;
        *) echo "Unsupported agent: $_agent" >&2; exit 2 ;;
      esac ;;
    project)
      case "$_agent" in
        claude) echo ".claude/skills" ;;
        codex) echo ".agents/skills" ;;
        cursor) echo ".cursor/skills" ;;
        opencode) echo ".opencode/skills" ;;
        *) echo "Unsupported agent: $_agent" >&2; exit 2 ;;
      esac ;;
    *) echo "Unsupported scope: $_scope" >&2; exit 2 ;;
  esac
}
```

```sh
#!/bin/sh
set -eu

ROOT=$(CDPATH= cd -- "$(dirname -- "$0")/.." && pwd)
. "$ROOT/scripts/path-lib.sh"

AGENT= SCOPE=user PREFIX= METHOD=symlink DRY_RUN=0
usage() { echo "Usage: install.sh --agent AGENT [--scope user|project] [--prefix DIR] [--copy|--symlink] [--dry-run]"; }

while [ "$#" -gt 0 ]; do
  case "$1" in
    --agent) [ "$#" -ge 2 ] || { usage >&2; exit 2; }; AGENT=$2; shift 2 ;;
    --scope) [ "$#" -ge 2 ] || { usage >&2; exit 2; }; SCOPE=$2; shift 2 ;;
    --prefix) [ "$#" -ge 2 ] || { usage >&2; exit 2; }; PREFIX=$2; shift 2 ;;
    --copy) METHOD=copy; shift ;;
    --symlink) METHOD=symlink; shift ;;
    --dry-run) DRY_RUN=1; shift ;;
    -h|--help) usage; exit 0 ;;
    *) echo "Unknown option: $1" >&2; usage >&2; exit 2 ;;
  esac
done

[ -n "$AGENT" ] || { echo "--agent is required" >&2; exit 2; }
reldir=$(bipit_resolve_reldir "$AGENT" "$SCOPE")

if [ "$SCOPE" = user ]; then
  base=${PREFIX:-$HOME}
else
  base=${PREFIX:-$(pwd)}
fi
bipit_validate_prefix "$base"

src=$ROOT/skills/bipit
dest=$base/$reldir
target=$dest/bipit
manifest=$dest/.bipit-install.tsv

if [ -e "$target" ] || [ -L "$target" ]; then
  echo "Refusing to overwrite existing path: $target" >&2
  exit 1
fi

if [ "$DRY_RUN" -eq 1 ]; then
  echo "Would install bipit skill to $target using $METHOD"
  exit 0
fi

mkdir -p "$dest"
complete=0
cleanup() {
  [ "$complete" -eq 1 ] && return
  if [ -L "$target" ]; then unlink "$target"
  elif [ -d "$target" ]; then find "$target" -depth -delete; fi
}
trap cleanup EXIT HUP INT TERM

if [ "$METHOD" = symlink ]; then
  ln -s "$src" "$target"
else
  cp -R "$src" "$target"
fi
printf 'bipit-v1\t%s\t%s\t%s\n' "$AGENT" "$SCOPE" "$METHOD" >> "$manifest"
complete=1
echo "Installed bipit skill to $target ($METHOD)"
```

```js
#!/usr/bin/env node
'use strict';
const path = require('node:path');
const { spawnSync } = require('node:child_process');

const AGENTS = ['claude', 'codex', 'cursor', 'opencode'];
const COMMANDS = ['install', 'uninstall'];

function buildArgs(argv) {
  const args = argv.slice();
  let command = 'install';
  if (args[0] && !args[0].startsWith('-')) {
    command = args.shift();
  }
  if (!COMMANDS.includes(command)) {
    throw new Error(`Unknown command: ${command}`);
  }
  let agent;
  const scriptArgs = [];
  for (let i = 0; i < args.length; i++) {
    const a = args[i];
    if (a === '--agent') { agent = args[++i]; scriptArgs.push('--agent', agent); }
    else scriptArgs.push(a);
  }
  if (!agent) throw new Error('--agent is required');
  let perAgent = null;
  if (agent === 'all') {
    perAgent = AGENTS.slice();
  } else if (!AGENTS.includes(agent)) {
    throw new Error(`Unsupported agent: ${agent}`);
  }
  return { command, agent, perAgent, scriptArgs };
}

function resolveScript(command) {
  return path.join(__dirname, '..', 'scripts', `${command}.sh`);
}

function run(argv) {
  let parsed;
  try { parsed = buildArgs(argv); }
  catch (e) { console.error(e.message); process.exit(2); }
  const script = resolveScript(parsed.command);
  const agents = parsed.perAgent || [parsed.agent];
  let failures = 0;
  for (const ag of agents) {
    const a = parsed.scriptArgs.map((x, i) =>
      (parsed.scriptArgs[i - 1] === '--agent' ? ag : x));
    const res = spawnSync('sh', [script, ...a], { stdio: 'inherit' });
    if (res.status !== 0) failures++;
  }
  process.exit(failures > 0 ? 1 : 0);
}

if (require.main === module) run(process.argv.slice(2));
module.exports = { buildArgs, resolveScript, AGENTS };
```

## Task 8: `scripts/watch.sh` (opt-in auto-commit)

**Files:**
- Create: `scripts/watch.sh`

**Interfaces:**
- Consumes: nothing.
- Produces: `watch.sh [dir]` (default `$HOME/bipit`) — polls every 5s (`git status --porcelain`), commits changes as `bipit: autosave <timestamp>`. Pure POSIX + git; no `inotify` dependency. Prints a line per commit. Ctrl-C to stop.

- [ ] **Step 1: Write `scripts/watch.sh`**

```sh
#!/bin/sh
set -eu
DIR=${1:-$HOME/bipit}
[ -d "$DIR/.git" ] || { echo "Not a git repo: $DIR" >&2; exit 1; }
echo "Watching $DIR — Ctrl-C to stop."
while :; do
  if [ -n "$(git -C "$DIR" status --porcelain)" ]; then
    git -C "$DIR" add -A
    git -C "$DIR" commit -q -m "bipit: autosave $(date -u +%Y-%m-%dT%H:%M:%SZ)"
    echo "committed $(date -u +%H:%M:%S)"
  fi
  sleep 5
done
```

- [ ] **Step 2: Test** — `sh -n scripts/watch.sh`; manual: `mkdir -p /tmp/w && git -C /tmp/w init -q && sh scripts/watch.sh /tmp/w &`, touch a file, see a commit, `kill %1`.
